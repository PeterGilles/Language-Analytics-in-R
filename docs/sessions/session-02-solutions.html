2.2 Exercise 2

Task: Download the first 3 works by Wells, H. G. (Herbert George), create a token table, then build a three-book dataset and compare top words.

wells_works <- gutenberg_works(author == "Wells, H. G. (Herbert George)") |>
  arrange(gutenberg_id) |>
  slice_head(n = 3)

wells_books <- gutenberg_download(wells_works$gutenberg_id, meta_fields = "title")

wells_tokens <- wells_books |>
  unnest_tokens(word, text) |>
  anti_join(stop_words, by = join_by(word))

wells_top <- wells_tokens |>
  count(title, word, sort = TRUE) |>
  group_by(title) |>
  slice_head(n = 12) |>
  ungroup()

wells_top |>
  mutate(word = fct_reorder(word, n)) |>
  ggplot(aes(x = n, y = word, fill = title)) +
  geom_col(show.legend = FALSE) +
  facet_wrap(vars(title), scales = "free_y") +
  labs(
    title = "Top words in Wells' books",
    x = "Count",
    y = NULL
  )

Interpretation note:

  • gutenberg_works(author == "Wells, H. G. (Herbert George)") returns metadata (including IDs) for that author.
  • arrange(gutenberg_id) |> slice_head(n = 3) keeps the first three works by Gutenberg ID.
  • wells_tokens gives a mini-corpus for Wells, and bind_rows() combines it with previously prepared token tables.
  • Shared high-frequency content words may reflect common literary vocabulary.
  • Distinctive words often point to characters, setting, or genre themes.

3 XML / LOD exercises — solutions

Build a reusable entry table:

lod_xml <- read_xml(resolve_path("new_lod-art.xml"))
entry_nodes <- xml_find_all(lod_xml, "//entry")
set.seed(42)
sample_n <- min(1000, length(entry_nodes))
entry_idx <- sample.int(length(entry_nodes), size = sample_n)
entry_sample <- entry_nodes[entry_idx]

node_text_or_na <- function(node, xpath) {
  candidate <- xml_find_first(node, xpath)
  if (inherits(candidate, "xml_missing")) {
    NA_character_
  } else {
    xml_text(candidate)
  }
}

For teaching speed, the solutions below use entry_sample (up to 1,000 random entries), not the full XML.

3.5 Exercise 5

Task: Keep entries with both IPA and an English translation, then compute the share.

xml_joined <- xml_tbl |>
  left_join(
    xml_first_translation |>

3.6 Exercise 6

Task: Extract partofspeech with lemma and list the 20 most frequent labels.

xml_pos <- entry_sample |>
  map(
    \(entry_node) {
      pos_values <- xml_find_all(entry_node, ".//partofspeech") |>
        xml_text()

      tibble(
        lemma = node_text_or_na(entry_node, ".//lemma"),
        partofspeech = pos_values |> first(default = NA_character_)
      )
    }
  ) |>
  list_rbind()

xml_pos |>
  filter(!is.na(partofspeech), partofspeech != "") |>
  count(partofspeech, sort = TRUE) |>
  slice_head(n = 20)
# A tibble: 0 × 2
# ℹ 2 variables: partofspeech <chr>, n <int>

Why this works:

  • xml_find_all(..., ".//partofspeech") collects part-of-speech nodes inside each entry.
  • first(default = NA_character_) keeps one value per entry and handles missing tags.
  • count(..., sort = TRUE) gives a frequency profile of grammatical categories.

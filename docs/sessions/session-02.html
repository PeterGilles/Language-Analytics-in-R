Author

0.1 Learning objectives

By the end of this session you will:

  • Load, inspect, and aggregate CSV data with tidyverse tools.
  • Import and inspect complex XML dictionary data (LOD).
  • Use XPath selectors to extract linguistic information from XML.
  • Build a tibble of example sentences from XML nodes.

1 Working with text data and corpora (data import)

For language analytics we usually work with tables (e.g. CSV or Excel) or text files.

1.4 Aggregating the data

With dplyr you can aggregate by groups (e.g. totals, means). Example: add a total population per commune, then show the top 10 communes by total population; or summarize across all rows (e.g. national totals by category).

# Total population per commune (using the pipe)
pop |>
  mutate(
    total = FEMMES_MINEURES + HOMMES_MINEURS + FEMMES_MAJEURES + HOMMES_MAJEURS
  ) |>
  arrange(desc(total)) |>
  select(COMMUNE_NOM, total) |>
  head(10)

2 Import LOD dictionary data (XML)

2.1 Getting the file

The LOD linguistic dataset is published as open data by the Luxembourg government (Zenter fir d’Lëtzebuerger Sprooch) under CC0 (LOD – Linguistesch Daten (resource)). Download the zip, extract it, and place the XML file (new_lod-art.xml, ~74 MB) in a folder in your project (e.g. data/).

Install once: install.packages("xml2"). Then load with library(xml2).

2.2 Reading the XML file

library(xml2)
Warning: package 'xml2' was built under R version 4.5.2
# Path to the XML file (e.g. in data/; adjust if your file is elsewhere)
lod_xml_path <- "new_lod-art.xml"

# Read XML from the folder
lod_xml <- read_xml(lod_xml_path)

# Root element
xml_name(lod_xml)
[1] "lod"
xml_children(lod_xml) |> length()
[1] 33737

2.3 Structure of the LOD XML

The document has a single root element <lod>, which contains many <entry> elements. Each entry has a lemma, pronunciation, grammatical structure, meanings, translations, and examples.

2.4 How XPath works

XPath selects nodes in the XML tree. In R, use xml_find_first() (one match) and xml_find_all() (all matches).

XPath Meaning Example
//entry any entry in document all entries
.//lemma lemma under current node current entry lemma
.//meaning/examples/example examples under meanings all examples for an entry
targetLanguage[@lang='en'] attribute filter English translation nodes

2.5 Inspecting one entry in R

2.6 Exploring the examples section

get_sentence <- function(ex) {
  text_node <- xml_find_first(ex, ".//text")
  if (inherits(text_node, "xml_missing")) return(NA_character_)
  tokens <- xml_find_all(text_node, "./*")
  paste(xml_text(tokens), collapse = " ")
}
library(tibble)

all_entries <- xml_find_all(lod_xml, "//entry")
set.seed(123)
sampled <- sample(length(all_entries), min(30, length(all_entries)))
rows <- list()

for (i in seq_along(sampled)) {
  entry <- all_entries[[sampled[i]]]
  lemma <- xml_find_first(entry, ".//lemma") |> xml_text()
  exs <- xml_find_all(entry, ".//meaning/examples/example")
  exs <- exs[1:min(2, length(exs))]
  for (ex in exs) {
    sent <- get_sentence(ex)
    if (!is.na(sent) && nchar(sent) > 0) {
      rows[[length(rows) + 1]] <- list(lemma = lemma, sentence = sent)
    }
  }
}

lod_examples <- tibble(
  lemma = vapply(rows, function(r) r$lemma, character(1)),
  sentence = vapply(rows, function(r) r$sentence, character(1))
)

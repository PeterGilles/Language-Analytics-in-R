Session 2 — Data import and exploratory analysis

Language Analytics in R

Author

Peter Gilles

0.1 Learning objectives

By the end of this session you will:

  • Import tabular, textual, and XML language data into R.
  • Use tidyverse workflows for exploratory statistics and visualization.
  • Tokenize and analyze Gutenberg texts with tidytext.
  • Extract structured information from LOD XML with xml2.
  • Solve format-specific exercises for CSV, text, and XML data.

This session covers three common data formats for language analytics:

  1. CSV (tabular data)
  2. Text from Project Gutenberg (tidytext workflow)
  3. XML from the LOD dictionary

Each section ends with dedicated exercises. Explained solutions are provided in sessions/session-02-solutions.qmd.

The LOD XML file can be downloaded from the Luxembourg open data portal (LOD resource).

xml_find_all(lod_xml, "//entry") |>

[1] 33737

What happens:

  • read_xml() loads the XML tree into memory.
  • xml_name() identifies the root node.
  • Counting //entry gives a first estimate of lexicon size.

XPath quick reminder:

XPath Meaning
//entry all entries
.//lemma lemma under current entry
.//ipa IPA node under current entry
.//targetLanguage[@lang='en']/translation English translations

4.2 Build a tidy tibble from XML

This block converts XML nodes into a tidy one-row-per-entry table.

# Full extraction over all entries is computationally heavy.
# We keep classroom render fast by using a sample.
entry_nodes <- xml_find_all(lod_xml, "//entry")
sample_n <- 1000
entry_idx <- sample.int(length(entry_nodes), size = sample_n)
entry_sample <- entry_nodes[entry_idx]

extract_entry <- function(entry_node) {
  en_translations <- xml_find_all(
    entry_node,
    ".//meaning/targetLanguage[@lang='en']/translation"
  ) |>
    xml_text()

  tibble(
    lemma = xml_find_first(entry_node, ".//lemma") |> xml_text(),
    ipa = xml_find_first(entry_node, ".//ipa") |> xml_text(),
    n_en_translations = length(en_translations),
    first_en_translation = en_translations |> first(default = NA_character_)
  )
}

lod_entries <- entry_sample |>
  map(extract_entry) |>
  list_rbind()

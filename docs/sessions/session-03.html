Session 3 — Corpus analysis with tidytext and quanteda

Language Analytics in R

Author

Peter Gilles

0.1 Learning objectives

By the end of this session you will:

  • Understand the difference between tidy text (one token per row) and corpus/dfm workflows.
  • Use tidytext to tokenize text and compute word frequencies.
  • Use quanteda to build a corpus and a document-term matrix (dfm).
  • Compare outputs from tidytext and quanteda on the same corpus.
  • Apply these workflows to linguistic/corpus questions.

1 Tidy text vs corpus objects

  • tidytext: one token per row (tibbles + dplyr pipeline).
  • quanteda: corpus objects and sparse matrices (dfm) for text mining.
  • Why both are useful in language analytics.

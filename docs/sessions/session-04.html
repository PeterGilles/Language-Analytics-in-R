1.3 Load RNPP population data

The RNPP file has one row per commune and sex (F / M), with population counts in 5-year age columns (AGE00_05, AGE05_10, …). We load it once and derive commune totals for the maps below.

pyramid_url <- "https://download.data.public.lu/resources/registre-national-des-personnes-physiques-rnpp-pyramide-dage-par-commune-population-age-pyramid-per-municipality/20260407-111759/31-03-2026-rnrpp-pyramide-age-commune.csv"

age_raw <- read_csv(pyramid_url)

1.4 Population per commune (choropleth)

This map visualizes total population (total_population) by commune.

How it works:

  1. Aggregate RNPP age columns to one total per commune (pop_by_commune).
  2. Join population values to commune polygons via commune name (id vs COMMUNE_NOM).
  3. Use fill = total_population to encode population with a color gradient.
  4. Optionally add commune labels at centroids for orientation.

Join. left_join() attaches total_population to every polygon row. The join uses two different column names: polygon id (commune name) matches RNPP COMMUNE_NOM. Rows without a match keep NA for total_population (grey on the map).

communes_df <- readRDS("communes_df.RDS")
centroids_label <- readRDS("centroids_label.RDS")

communes_pop_map <- communes_df |>
  left_join(pop_by_commune, by = c("id" = "COMMUNE_NOM"))

Plot. In aes(), group = group is essential for polygons: each commune consists of many coordinate rows that must be drawn as one shape. fill = total_population maps population to colour. geom_text() uses a separate table (centroids_label); inherit.aes = FALSE prevents it from inheriting fill and group from the polygon layer. coord_quickmap() sets the map extent; scale_fill_viridis_c() applies a continuous colour scale with readable axis labels.

ggplot(communes_pop_map, aes(x = long, y = lat, group = group, fill = log(total_population))) +
  geom_polygon(color = "white", linewidth = 0.15) +
  geom_text(
    data = centroids_label,
    aes(x = long, y = lat, label = label),
    inherit.aes = FALSE,
    size = 2.4,
    color = "grey20"
  ) +
  coord_quickmap(xlim = c(5.5, 6.7), ylim = c(49.2, 50.2)) +
  scale_fill_viridis_c(option = "plasma", labels = scales::label_number(big.mark = " ")) +
  labs(
    title = "Luxembourg: population by commune",
    subtitle = "RNPP, 31 March 2026 — sum of all age bands",
    fill = "Population",
    x = "Longitude",
    y = "Latitude"
  ) +
  theme_void()
  • Brighter communes have higher population totals.
  • Luxembourg City should stand out clearly as the most populous commune.
  • A few communes were merged or renamed since the polygon file was built; unmatched polygons have no fill.

1.6 Maps by sex with facet_wrap()

The RNPP table has separate rows for F and M. After summing population per commune and sex, we can plot two choropleths side by side with facet_wrap(~ SEXE).

How it works:

  1. Aggregate total_population by COMMUNE_NOM and SEXE (not merged across sexes).
  2. Join to communes_df — each commune polygon appears twice (once per sex).
  3. Add facet_wrap(~ SEXE) so ggplot draws one map panel per sex.
pop_by_commune_sex <- age_raw |>
  mutate(across(starts_with("AGE"), as.numeric)) |>
  summarise(
    total_population = sum(across(starts_with("AGE")), na.rm = TRUE),
    .by = c(COMMUNE_NOM, SEXE)
  )

communes_pop_sex <- communes_df |>
  left_join(pop_by_commune_sex, by = c("id" = "COMMUNE_NOM")) |>
  na.omit()

ggplot(communes_pop_sex, aes(x = long, y = lat, group = group, fill = ntile(total_population, 5))) +
  geom_polygon(color = "white", linewidth = 0.15) +
  coord_quickmap(xlim = c(5.5, 6.7), ylim = c(49.2, 50.2)) +
  facet_wrap(
    ~ SEXE,
    labeller = labeller(SEXE = c(F = "Women", M = "Men"))
  ) +
  scale_fill_viridis_c(option = "plasma", labels = scales::label_number(big.mark = " ")) +
  labs(
    title = "Population by commune and sex",
    subtitle = "RNPP, 31 March 2026 — same fill scale in both panels",
    fill = "Population"
  ) +
  theme_void() +
  theme(strip.text = element_text(face = "bold"))
  • facet_wrap(~ SEXE) splits the plot into one panel per sex. The formula ~ SEXE means “create facets from the SEXE column”. Each panel reuses the same geom_polygon() call; ggplot filters the data automatically.
  • labeller = labeller(...) renames facet strip labels (F → “Women”, M → “Men”) without changing the underlying data.
  • scale_fill_viridis_c() defines one continuous colour scale for both panels, so darker/brighter communes are comparable across women and men.
  • theme(strip.text = ...) formats the facet titles (the strips above each small map).

Both panels share the same colour scale by default, which makes the two maps comparable.

1.7 Age pyramids

Using the same age_raw table, reshape the wide age columns into long format. For a classic pyramid, plot men with negative counts (left) and women with positive counts (right).

1.7.1 One commune

commune_pick <- "Differdange"

age_levels <- age_raw |>
  select(starts_with("AGE")) |>
  names() |>
  str_remove("^AGE") |>
  str_replace("_", "-") |>
  (\(x) if_else(x == "100-", "100+", x))()

Reshape. The RNPP table is wide: one column per age band. pivot_longer() stacks them into rows (age_band, count). We then clean band labels (AGE20_25 → 20-25) and fix the order with factor(..., levels = age_levels). Multiplying men’s counts by −1 places their bars on the left of the pyramid; women stay positive on the right.

age_pyramid <- age_raw |>
  filter(COMMUNE_NOM == commune_pick) |>
  pivot_longer(starts_with("AGE"), names_to = "age_band", values_to = "count") |>
  mutate(
    age_band = str_remove(age_band, "^AGE"),
    age_band = str_replace(age_band, "_", "-"),
    age_band = if_else(age_band == "100-", "100+", age_band),
    age_band = factor(age_band, levels = age_levels),
    count = if_else(SEXE == "M", -count, count)
  )

Plot. geom_col() draws horizontal bars; geom_vline(xintercept = 0) marks the centre line between women and men. scale_x_continuous(labels = ...) uses abs() so axis labels show positive numbers even though men’s values are negative.

ggplot(age_pyramid, aes(x = count, y = age_band, fill = SEXE)) +
  geom_col(width = 0.85) +
  geom_vline(xintercept = 0, linewidth = 0.3) +
  scale_fill_manual(
    values = c(F = "#c0392b", M = "#2980b9"),
    labels = c(F = "Women", M = "Men")
  ) +
  scale_x_continuous(labels = \(x) format(abs(x), big.mark = " ")) +
  labs(
    title = paste("Age pyramid:", commune_pick),
    subtitle = "RNPP, 31 March 2026 — counts by 5-year age band",
    x = "Population",
    y = "Age group",
    fill = NULL
  ) +
  theme_minimal() +
  theme(legend.position = "bottom")

Change commune_pick (e.g. to "Luxembourg" or "Esch-sur-Alzette") to compare age structures.

1.7.2 Entire country

Aggregate age_raw across all communes, keeping all age columns and grouping by sex.

Summarise. summarise(across(...), .by = SEXE) adds up every age column across all communes, but keeps women and men in separate rows. The result is still wide (one column per age band).

Age order. The pipeline on age_levels extracts column names, removes the AGE prefix, and turns underscores into hyphens. The anonymous function \(x) if_else(...) is a short way to relabel the top band 100- as 100+.

Long format. The same pivot_longer() + mutate() steps as above turn the national table into pyramid-ready data.

age_total <- age_raw |>
  summarise(
    across(starts_with("AGE"), \(x) sum(x, na.rm = TRUE)),
    .by = SEXE
  )

age_levels <- age_total |>
  select(starts_with("AGE")) |>
  names() |>
  str_remove("^AGE") |>
  str_replace("_", "-") |>
  (\(x) if_else(x == "100-", "100+", x))()

age_pyramid <- age_total |>
  pivot_longer(starts_with("AGE"), names_to = "age_band", values_to = "count") |>
  mutate(
    age_band = str_remove(age_band, "^AGE"),
    age_band = str_replace(age_band, "_", "-"),
    age_band = if_else(age_band == "100-", "100+", age_band),
    age_band = factor(age_band, levels = age_levels),
    count = if_else(SEXE == "M", -count, count)
  )

ggplot(age_pyramid, aes(x = count, y = age_band, fill = SEXE)) +
  geom_col(width = 0.85) +
  geom_vline(xintercept = 0, linewidth = 0.3) +
  scale_fill_manual(
    values = c(F = "#c0392b", M = "#2980b9"),
    labels = c(F = "Women", M = "Men")
  ) +
  scale_x_continuous(labels = \(x) format(abs(x), big.mark = " ")) +
  labs(
    title = paste("Age pyramid: Luxembourg"),
    subtitle = "RNPP, 31 March 2026 — counts by 5-year age band",
    x = "Population",
    y = "Age group",
    fill = NULL
  ) +
  theme_minimal() +
  theme(legend.position = "bottom")

2.2 Variant statistics by age, gender, education, and dialect area

Reshape the four sociolinguistic variables into long format, then compute counts and row-wise shares (distribution of variants within each age group, etc.).

Convert to character. Alter, Geschlecht, and the other columns are factors or ordered factors. pivot_longer() needs a common type in the values column, so we convert them to character first.

Long format. pivot_longer() stacks the four columns into two new ones: variable (which social factor) and level (the actual category, e.g. “25 bis 34”).

Counts and shares. count() tallies recordings per social group and variant. group_by(variable, level) + mutate(share = n / sum(n)) computes the proportion of each variant within each age band (or gender, etc.) — the values in one row of the output sum to 1.

variant_by_social <- butterfly_variants |>
  mutate(across(
    c(Alter, Geschlecht, Ausbildung, Dialektgebiet),
    \(x) as.character(x)
  )) |>
  pivot_longer(
    c(Alter, Geschlecht, Ausbildung, Dialektgebiet),
    names_to = "variable",
    values_to = "level"
  ) |>
  count(variable, level, Variant_Päiperlek) |>
  group_by(variable, level) |>
  mutate(share = n / sum(n), .groups = "drop") |>
  arrange(variable, level, desc(n))

2.3 Map variants by commune

Aggregate to commune level: number of recordings, share of the standard form Päiperlek, and the dominant variant (most frequent code in that commune).

commune_variants <- butterfly_variants |>
  mutate(Gemeng = as.character(Gemeng)) |>
  summarise(
    n = n(),
    share_päiperlek = mean(Variant_Päiperlek == "Päiperlek"),
    .by = Gemeng
  ) |>
  left_join(
    butterfly_variants |>
      mutate(Gemeng = as.character(Gemeng)) |>
      count(Gemeng, Variant_Päiperlek) |>
      slice_max(n, n = 1, by = Gemeng, with_ties = FALSE) |>
      select(Gemeng, dominant_variant = Variant_Päiperlek),
    by = "Gemeng"
  )

2 Introduction to quanteda

quanteda is a text analysis framework for R that is optimized for corpus workflows:

  • keep original texts in a corpus,
  • transform texts into tokens,
  • represent token counts in a sparse matrix (dfm),
  • combine textual data with metadata (docvars) for linguistic and social analysis.

In short: quanteda is useful when you want transparent preprocessing, efficient counting, and reproducible corpus-based analysis.

2.1 1) Build a corpus from built-in quanteda data

data_corpus_inaugural is bundled with quanteda and contains U.S. inaugural speeches with document metadata (docvars) such as Year, President, and Party.

In quanteda, docvars are document-level variables attached to each text (comparable to columns in a metadata table).
They are crucial because they let us:

  • filter documents (corpus_subset(corp, Year >= 1993)),
  • compare groups (dfm_group(..., groups = Party)),
  • model textual outcomes with external information.

The goal of this first step is to inspect the corpus structure before any preprocessing:

  • how many documents we have,
  • how large they are,
  • which metadata variables are available for grouping and filtering.

2.3 3) Tokenize and preprocess

This is the central preprocessing step:

  • tokens() splits text into tokens,
  • remove_punct and remove_numbers reduce noise,
  • tokens_tolower() normalizes case,
  • tokens_remove(stopwords("en")) removes frequent function words.

We keep the original corpus unchanged and store transformed text in a new object (toks_recent).

toks_recent <- tokens(
  corp_recent,
  remove_punct = TRUE,
  remove_numbers = TRUE
) |>
  tokens_tolower() |>
  tokens_remove(stopwords("en")) |>
  tokens_wordstem(
  language = quanteda_options("language_stemmer"),
  verbose = quanteda_options("verbose")
)

2.5 5) Create and inspect a dfm

A document-feature matrix (dfm) is a sparse matrix with:

  • rows = documents,
  • columns = features (tokens),
  • cells = feature counts.

Why this matrix matters:

  • it transforms text into a numeric format required for statistics and machine learning,
  • it is sparse and memory-efficient (important for large corpora),
  • it allows direct operations such as feature selection, weighting, grouping, and modeling.

Typical use cases include keyness analysis, topic/style comparison, supervised classification, and dimensional reduction.

# Build document-feature matrix from cleaned tokens

2.7 7) Simple dictionary analysis

A dictionary maps many individual words to a smaller set of analytical categories.
Here we define three thematic categories and then count category matches per document.

Pedagogically, this demonstrates how to move from raw lexical frequencies to theory-driven categories.

# Define a small dictionary with 3 thematic categories
issue_dict <- dictionary(
  list(
    economy = c("economy", "jobs", "work", "business", "growth"),
    security = c("security", "terror", "terrorism", "war", "threat"),
    democracy = c("democracy", "freedom", "rights", "constitution", "people")
  )
)

# Map matching tokens to dictionary categories, then count by document
dfm_dict <- toks_recent |>
  tokens_lookup(dictionary = issue_dict) |>
  dfm()

3 Quanteda with Gutenberg data

We now repeat the workflow on an external corpus from Project Gutenberg, using German literary texts.

For these Faust texts, a direct UTF-8 text import is more reliable than gutenberg_download() and avoids encoding artifacts that can split words into fragments.

load_faust_lines <- function(gutenberg_id, title, author) {
  url <- sprintf(
    "https://www.gutenberg.org/cache/epub/%s/pg%s.txt",
    gutenberg_id, gutenberg_id
  )
  con <- url(url)
  on.exit(close(con), add = TRUE)

  lines <- readLines(con, warn = FALSE, encoding = "UTF-8")
  lines <- gutenbergr::gutenberg_strip(lines)

  tibble(
    gutenberg_id = gutenberg_id,
    title = title,
    author = author,
    text = lines
  )
}

4 Introduction to ggplot2

4.1 Generic introduction

ggplot2 is based on the grammar of graphics.
The core idea is that every plot is built from the same components:

  • data (the dataset),
  • aesthetics (aes(): which variable maps to x, y, color, etc.),
  • geometry (geom_*(): bars, points, lines, polygons),
  • optional layers (labels, scales, themes, facets).

The canonical structure is:

ggplot(data = ..., aes(x = ..., y = ...)) + 
  geom_...() +
  labs(...) +
  theme_minimal()

Note that the components in ggplot2 are connected with the + sign.

4.2 First plots

The dataset mpg is included in ggplot2.
Each row is a car model observation, with variables such as:

  • class: vehicle type (SUV, compact, etc.),
  • manufacturer: car brand,
  • displ: engine displacement (liters),
  • hwy: highway fuel economy (miles per gallon).

It is a good teaching dataset because it contains both categorical and numeric variables. When ggplot2 is loaded, the dataset is immediately available as mpg.

ggplot(data = mpg, aes(x = class)) +
  geom_bar()
ggplot(mpg, aes(x = class)) +
  geom_bar(fill = "steelblue") +
  coord_flip() +
  labs(
    title = "Number of cars by class",
    x = "Car class",
    y = "Count"
  ) +
  theme_minimal()

4.3 Bar charts

geom_bar() counts rows automatically.
geom_col() expects a pre-computed y-value.

When to use which:

  • Use geom_bar() if your question is “how many observations are in each category?”.
  • Use geom_col() if you already calculated a statistic (mean, median, sum) per category.

In the first example, ggplot2 performs the counting for us.

ggplot(mpg, aes(x = manufacturer)) +
  geom_bar(fill = "darkorange") +
  coord_flip() +
  labs(
    title = "Observations by manufacturer",
    x = "Manufacturer",
    y = "Count"
  ) +
  theme_minimal()
# First, compute mean highway fuel economy by car class
mean_hwy_by_class <- mpg |>
  summarise(mean_hwy = mean(hwy), .by = class)

# Then plot those pre-computed values
ggplot(mean_hwy_by_class, aes(x = class, y = mean_hwy)) +
  geom_col(fill = "seagreen") +
  coord_flip() +
  labs(
    title = "Mean highway MPG by class",
    x = "Class",
    y = "Mean highway MPG"
  ) +
  theme_minimal()

4.4 Boxplots and violin plots with iris

The iris dataset is a classic built-in dataset with 150 flowers from 3 species:

  • Sepal.Length, Sepal.Width, Petal.Length, Petal.Width (numeric measurements),
  • Species (categorical label: setosa, versicolor, virginica).

A boxplot summarizes distribution (median, quartiles, outliers).
A violin plot shows the full density shape of the distribution.

Color options you can discuss with students:

  • Set one fixed color: fill = "steelblue" in geom_*().
  • Map color/fill to a variable: aes(fill = Species).
  • Use manual palettes: scale_fill_manual(values = c(...)).
  • Use ColorBrewer palettes: scale_fill_brewer(palette = "Set2").
